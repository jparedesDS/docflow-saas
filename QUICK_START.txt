REFERENCIAS RÁPIDAS
═══════════════════
¿Qué es TNEF?
  → Formato Microsoft/Outlook que encapsula HTML
  → Requiere librería tnefparse para decodificar
  → GAIA (Technip) usa este formato

¿Por qué falla ahora?
  → Código intenta TNEF.htmlbody pero sin try/except
  → Si htmlbody vacío, no intenta rtfbody o body
  → Sin logging para debuggear

¿Necesito striprtf?
  → Solo si GAIA tiene rtfbody
  → Test de diagnóstico lo muestra
  → Si rtfbody > 0 bytes → pip install striprtf

¿Esto rompe TR/ACONEX/SENDOC?
  → NO, el código nuevo sigue soportando text/html directo
  → Intento 1: HTML directo (TR, ACONEX, SENDOC) ✓
  → Intento 2: TNEF (GAIA) ✓
  → Fallbacks preservados
